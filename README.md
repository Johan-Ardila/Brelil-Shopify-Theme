# Brelil Shopify Theme 

Tema personalizado y optimizado para Shopify, diseñado para ofrecer una experiencia de comercio electrónico rápida, fluida y centrada en la conversión para productos de belleza y cuidado personal.

---

## Características Principales

* **Diseño Responsivo:** Adaptado perfectamente a dispositivos móviles, tabletas y equipos de escritorio.
* **Secciones Dinámicas:** Bloques personalizables desde el editor de Shopify para una gestión de contenidos flexible.
* **Optimización de Rendimiento:** Carga rápida y buenas prácticas de SEO técnico implementadas en el código base.
* **Experiencia de Compra Fluida:** Carrito deslizante (*cart drawer*), integración de variantes avanzada y llamadas a la acción optimizadas.

---

## Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando el ecosistema oficial de desarrollo de Shopify:

* **Liquid:** Lenguaje de plantillas oficial de Shopify.
* **HTML5 / CSS3 (Sass):** Estructura y diseño modular de estilos.
* **JavaScript (ES6+):** Interactividad del lado del cliente, gestión del carrito y componentes dinámicos.
* **Shopify CLI:** Herramienta para el desarrollo local, sincronización y despliegue de temas.

---

## Estructura del Proyecto

La estructura de directorios sigue los estándares recomendados por Shopify:

```text
├── assets/        # Archivos estáticos (CSS compilado, JavaScript, imágenes)
├── config/        # Configuración del tema (settings_schema.json, settings_data.json)
├── layout/        # Plantillas base principales (theme.liquid)
├── locales/       # Archivos de traducción e internacionalización
├── sections/      # Secciones modulares reutilizables del tema
├── snippets/      # Fragmentos de código reutilizables (tarjetas de producto, etc.)
└── templates/     # Plantillas de vistas (index, product, collection, cart, etc.)
